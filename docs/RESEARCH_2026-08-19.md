# Public Landscape Research — 19 August 2026

## Finding

The broad category is not unique. Public projects already cover combinations of:
- local LLM/API gateways;
- multi-provider routing;
- coding-client gateway/proxy workflows;
- provider/model mapping;
- fallback.

Examples reviewed in the earlier landscape survey included:
- 9Router
- Claude Code Router
- Claude Code Provider Gateway (CCPG)
- ferryllm
- LiteLLM
- OpenRouter as a cloud routing reference

## MMG positioning

The stronger productization position is the combination of:

1. Windows-first single-EXE shell experience;
2. one-click Codex / ChatGPT Desktop + Claude Code Desktop setup workflow;
3. local routing/provider/model control;
4. guided provider credential setup;
5. device-bound commercial licensing;
6. verifiable binary distribution.

The public survey did not establish an exact match for the complete productization combination.

## Claim policy

Recommended:
- “Windows-first local AI routing control plane”
- “One EXE. One Control Plane. Many AI Providers.”
- “verifiable releases”

Avoid:
- “world’s first”
- “unhackable”
- “impossible to reverse engineer”

This is a practical market/repository survey, not a patentability or freedom-to-operate legal opinion.
