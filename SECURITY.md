# Security Policy

## Reporting

Please use GitHub **Private Vulnerability Reporting / Security Advisories** when enabled for this repository.

Do not post a public issue containing:

- API keys or access tokens;
- license-signing private keys;
- code-signing certificates/private keys;
- working license-bypass details;
- credentials;
- sensitive logs or personal machine paths.

## Product statement

MMG AI Router should be described as **tamper-resistant / verifiable** only for controls that have actually been implemented and tested. It should never be described as unbreakable or impossible to reverse engineer.

## Scope

Useful reports include:
- release integrity failures;
- update verification problems;
- credential exposure;
- license authorization errors;
- unsafe local-agent capability exposure;
- unintended remote network exposure.
